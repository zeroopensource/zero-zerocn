Fix the next.out directory issue.

### Usage


Install package

```bash
pnpm dlx shadcn@latest add https://zerocn.zeroopensource.org/r/fix-next-out.json
```

Install package ([workspace](/docs/workspace))

```bash
pnpm --filter=$WORKSPACE shadcn add https://zerocn.zeroopensource.org/r/fix-next-out.json
```

Add script

```json
{
  "scripts": {
    "build": "next build && pnpm fix:next-out",
    "fix:next-out": "tsx src/lib/fix-next-out.ts",
  }
}

```
